# Экспорт дизайна из Figma

Плагин Figma плюс конвертер: токены из макета попадают в SCSS проекта, а структура
выделенных фреймов - в JSON. По этому JSON агент верстает экран по точным размерам,
а не «на глаз» по скриншоту.

Сами макеты в Figma собирает генератор [`tools/figma-generator`](../figma-generator/README.md):
он создает страницу «Норма · макеты», фреймы, переменные и текстовые стили.

## Что выгружается

- переменные Figma (цвета, числа, строки, флаги) со всеми режимами (modes);
- локальные стили: заливки, текстовые, эффекты (тени), сетки;
- дерево выделенных фреймов: слои, размеры, координаты, авторазметка, отступы,
  радиусы, эффекты, тексты, привязка цвета к переменной или к стилю;
- сводка частот: какие цвета, кегли, радиусы и отступы реально встречаются и
  сколько раз.

Плагин работает без сети: в манифесте `networkAccess` запрещает запросы, данные
уходят только в панель плагина. Сборка не нужна - обычный JS, Figma API 1.0.0.

## Установка

1. Открой файл в Figma Desktop.
2. Меню `Plugins` - `Development` - `Import plugin from manifest...`.
3. Укажи `tools/figma-plugin/manifest.json`.
4. В списке Development появится `Norma · экспорт дизайна`.

Поле `id` в манифесте не указано: оно нужно для публикации в Community, локальному
плагину не требуется. Если твоя версия Figma попросит id, впиши любое число,
например `777000111`.

## Как пользоваться

1. Выдели один или несколько фреймов.
2. Запусти плагин, оставь галочки включенными, нажми «Собрать JSON».
3. Нажми «Скачать .json». Если скачивание внутри Figma не сработало - «Копировать»
   и вставь в файл сам.
4. Положи файл в репозиторий: `design/figma-<дата>.json`.

Из корня репозитория собери стили:

```powershell
node tools/figma-plugin/to-scss.mjs design/figma-2026-11-25.json web/src/styles/_tokens.scss
```

И подключи их в `web/src/styles.scss` первой строкой, до остальных правил. Делать это
нужно после первой генерации файла, иначе сборка упадет на отсутствующем `@use`:

```scss
@use 'styles/tokens';
```

После этого в компонентах доступны `var(--color-...)`, `var(--radius-...)`,
`var(--space-...)`. Мапы `$typography`, `$text-styles`, `$color-styles`, `$shadows`
лежат в том же файле: подключай `@use 'styles/tokens' as *`, чтобы обращаться к ним
без префикса, или `@use 'styles/tokens'` и пиши `tokens.$typography`.

## Что получается в SCSS

```scss
:root {
  --color-text-primary: #2f855a;
  --color-surface-card: #ffffff;
  --radius-card: 12px;
  --space-16: 16px;
}

[data-theme='темная'] {
  --color-text-primary: #48bb78;
  --color-surface-card: #1f2937;
}

$typography: (
  'inter-600-24': (family: 'Inter', weight: 600, size: 24px, line-height: 32px, usage: 2),
);
```

## Границы

- потолок обхода - 4000 узлов и глубина 60. На огромном выделении в JSON будет
  `meta.truncated: true`, часть дерева пропущена: уменьши выделение и повтори;
- картинки не выгружаются, только текстовые данные;
- переменные и стили - только локальные. Переменные из подключенных библиотек
  попадут в узлы как id без имени;
- режимы (modes): первый режим идет в `:root`, остальные, если отличаются, -
  в `[data-theme='<режим>']`;
- числовые переменные Figma (FLOAT) выводятся с `px`, кроме имен со словами
  opacity, weight, ratio, scale, factor, line, z-index;
- радиусы и отступы из сводки частот не дублируют значения, уже заданные
  переменными;
- один и тот же цвет, заданный и переменной, и руками, в сводке считается
  отдельно: так видно, где макет разъехался;
- если переменных в файле нет, цвета получают имена `--color-1`, `--color-2` и
  комментарий с исходным hex. Заведи переменные в Figma, когда палитра устоится.

## Файлы

| Файл | Что делает |
|---|---|
| `manifest.json` | манифест плагина |
| `code.js` | сбор данных в песочнице Figma |
| `ui.html` | панель плагина: галочки, просмотр, копирование, скачивание |
| `to-scss.mjs` | конвертер JSON в SCSS |
| `check.mjs` | проверка `code.js` на заглушке Figma API, без редактора |
| `sample.tokens.json` | пример экспорта, чтобы проверить конвертер без Figma |

## Проверка без Figma

```powershell
node --check tools/figma-plugin/code.js
node tools/figma-plugin/check.mjs
node tools/figma-plugin/to-scss.mjs tools/figma-plugin/sample.tokens.json $env:TEMP\tokens.scss
```

- первая команда проверяет синтаксис плагина;
- вторая гоняет `code.js` на заглушке Figma API: фрейм, текст с разными стилями в
  абзаце, инстанс компонента, переменные и стили. Ловит опечатки в обращениях к
  API и падение на `mixed` значениях до запуска в редакторе;
- третья проверяет конвертер на сохраненном примере: печатает, сколько токенов
  собрал, и пишет SCSS.
