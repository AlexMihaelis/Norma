# Генератор макетов «Нормы» в Figma

Плагин создает в файле Figma страницу `Норма · макеты` с шестью фреймами и
дизайн-системой. Руками рисовать не нужно: макеты собираются кодом по
утвержденным черновикам, а потом выгружаются в SCSS плагином
[`tools/figma-plugin`](../figma-plugin/README.md).

## Что создается

| Объект | Что внутри |
|---|---|
| Переменные | 16 цветов (`color/*`) и 12 чисел (`radius/*`, `space/*`) |
| Текстовые стили | 13 штук: `Heading/H1…H5`, `Body/*`, `Caption`, `Micro` |
| Фреймы | Главная, Дневник, Вес, Статистика, Профиль, Форма замера |

Фреймы ставятся в ряд с отступом 120 px, каждый шириной 1440 px. Внутри -
реальная структура: карточки, тексты, кнопки, поля, столбцы, кольцо БЖУ.

## Установка

1. Открой файл в Figma Desktop.
2. Главное меню (логотип Figma слева сверху) - `Plugins` - `Development` -
   `Import plugin from manifest...`
3. Укажи `tools/figma-generator/manifest.json`.
4. В списке Development появится `Norma · генератор макетов`.

Если Figma попросит `id` манифеста, впиши любое число: поле нужно только для
публикации.

## Запуск

1. Запусти плагин и нажми «Создать макеты».
2. Через несколько секунд появится страница `Норма · макеты` с шестью фреймами.

Повторный запуск безопасен: плагин находит свою страницу, очищает ее и собирает
заново, а переменные и текстовые стили переиспользует по имени и обновляет
значения. Дублей не будет.

## Как получить токены

1. На странице `Норма · макеты` выдели все шесть фреймов (`Ctrl+A`).
2. Запусти плагин `Norma · экспорт дизайна` (из `tools/figma-plugin`).
3. «Собрать JSON» - «Скачать .json», положи файл в `design/`.
4. Из корня репозитория:

```powershell
node tools/figma-plugin/to-scss.mjs design/figma-<дата>.json web/src/styles/_tokens.scss
```

Теперь цвета в Figma имеют имена (`color/accent`), поэтому в SCSS попадут
`--color-accent`, `--radius-card`, `--space-16`, а не `--color-1`.

## Ограничения

- **Знак логотипа упрощен**: плашка, буква N и лист эллипсом. В вебе знак
  рисуется кодом точнее.
- **Графики** - отрезки линий и кружки, без заливки под кривой. В Figma заливку
  проще дорисовать руками, чем генерировать вектор.
- **Кольцо БЖУ** - через `arcData` эллипса, поэтому сегменты чуть отличаются от
  картинки по толщине шва.
- **Шрифт Inter** вместо Segoe UI: в Figma он есть по умолчанию, в вебе пока
  системный. Если решим перевести приложение на Inter, токены уже будут готовы.
- **Тени не переносятся**: в макетах карточки отделены рамкой, а не тенью.

## Файлы

| Файл | Что делает |
|---|---|
| `manifest.json` | манифест плагина |
| `code.js` | генерация страницы, фреймов, переменных и стилей |
| `ui.html` | панель с кнопкой и статусом |
| `check.mjs` | проверка на заглушке Figma API, без редактора |

## Проверка без Figma

```powershell
node --check tools/figma-generator/code.js
node tools/figma-generator/check.mjs
```

Вторая команда запускает `code.js` в песочнице node с подставным `figma` и
проверяет, что созданы 28 переменных, 13 текстовых стилей и шесть непустых
фреймов. Это ловит опечатки в API до запуска в редакторе.
